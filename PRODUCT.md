# Product

register: product

DNA mutation explorer is a browser lab and an npm package for DNA models.
Visitors expose flexible DNA to damaging factors and compare protective mechanisms.
The lab connects visible lesions with schematic atomic events.
The main question is which damage forms and which protection acts on it.

The TypeScript core works without React or a browser.
The React components work in scientific websites and interactive lessons.
The demo uses the same package code as the component on esmirnov.ai.

`DnaDamageLab` is the main experience.
Start the molecular motion on load.
Provide independent UV, X-ray, heat, electric-field, and oxidant factors.
Provide separate antioxidants, UV filters, X-ray shields, repair, and repair light.
Keep pause and reset visible.
Use no rounds, scores, target sequences, or quizzes in this component.

Use known DNA bases with `A`–`T` and `G`–`C` pairing.
Place UV dimers between neighboring pyrimidines on the same strand.
Separate thermal strand opening from chemical lesions.
Use electric forces for motion without automatic radiation damage.
Keep lesion records separate from the DNA letters.
Do not turn every damaged base into an ordinary letter substitution.

Let antioxidants act only on reactive oxygen in this model.
Let filters attenuate their exposure channels.
Let repair act on existing lesions.
Keep the same sequence and existing damage when the species context changes.
Use species contexts for qualitative repair settings, not resistance rankings.

Bare DNA has no intrinsic cellular repair.
E. coli can use photolyase with repair light.
Human cells and D. radiodurans have no photolyase in this model.
D. radiodurans illustrates strong repair and protein protection.
Its DNA is not invulnerable.

Show sequence states and model limits.
Do not infer disease risk, protein function, protein structure, or gene expression from the sequence.
Identify the example sequence as synthetic.
Keep all sequence data in the browser.

Use Eduard's established sage and clay palette.
Use a small set of native controls and thin rules.
Use text and color to identify exposures, lesions, protection, and repair.
Keep the task visible on phones.
Use letters and labels with color to show changes.
Do not use decorative cards, fake measurements, or a large promotional header.

`MutationExplorer` is an optional advanced sequence editor.
It compares exact coding-sequence edits, RNA codons, and amino acids.
It keeps the existing eight guided challenges, codon reference, and sequence export.
Keep that editor separate from the main canvas experience.

`DnaPlayground` is a separate copy-and-repair utility.
It keeps the existing mismatch, repair, and selected-descendant mechanics.

Atomic events, electron paths, motion, and force are illustrative.
Do not imply calibrated doses, reaction rates, chemical forces, survival, or health risk.
Honor reduced-motion preferences.
Keep direct experiments usable while motion is paused.
