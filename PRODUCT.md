# Product

register: product

DNA mutation explorer is a browser tool and an npm package for coding DNA edits.
Teachers, students, and developers compare DNA, RNA codons, and amino acids in one interface.
The TypeScript core works without React or a browser.
The React component works in scientific websites and interactive lessons.
The demo uses the same package code as the component on esmirnov.ai.

Use the standard genetic code for a coding sequence in the 5-prime to 3-prime direction.
Show sequence consequences and model limits.
Do not infer disease risk, protein function, protein structure, or gene expression from the sequence.
Identify the example sequence as synthetic.
Keep all sequence data in the browser.

Use Eduard's established sage and clay palette.
Use a small set of native controls and thin rules.
Use linked selections to connect DNA bases, codons, and amino acids.
Keep the task visible on phones.
Use letters and labels with color to show changes.
Do not use decorative cards, fake measurements, or a large promotional header.

The first release supports one edit relative to the reference sequence.
The edit can substitute, insert, or delete bases.
The browser component supports example edits, custom sequences, direct base selection, and sequence export.
